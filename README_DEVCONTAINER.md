# Dev Environment

This repo uses Qadiff devcontainer scaffolding generated by `qadiff-dct`.

Note: In devcontainers, Git may warn about 'unsafe repository' due to ownership differences.
This template auto-configures Git `safe.directory` for the current workspace only.

## Quickstart
1) Open in VS Code
2) Run: Dev Containers: Reopen in Container
3) Use Claude Code in terminal
